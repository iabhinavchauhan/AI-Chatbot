# 🤖 AI Chatbot

A simple and interactive **AI Chatbot Web Application** built using **HTML & CSS**, with an integrated **Zapier Chatbot** for handling conversations.

🌐 **Live Demo:**
https://iabhinavchauhan.github.io/AI-Chatbot/

---

## ✨ Features

* 🤖 Integrated Zapier AI Chatbot
* 💬 Interactive conversational interface
* 🎨 Clean and simple UI
* 📱 Responsive design
* ⚡ Lightweight and fast
* 🔗 Seamless Zapier Bot integration
* 🌐 Hosted with GitHub Pages

---

## 🛠️ Tech Stack

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **Zapier Chatbots** – AI chatbot integration
* **GitHub Pages** – Deployment

## ⚙️ How It Works

The website interface is created using **HTML and CSS**.

The chatbot functionality is provided through **Zapier Chatbots**, which is integrated into the webpage to provide an interactive AI-powered conversational experience.

### Workflow

```text
User
  ↓
AI Chatbot Interface
  ↓
Zapier Chatbot
  ↓
AI Response
  ↓
User
```
